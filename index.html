1. Jaccard Similarity Coefficient

Measures similarity between finite sample sets. In our system, set $A$ is the user's preferred genres and set $B$ is the candidate movie's genres:

J(User, Movie) = |User ∩ Movie| / |User ∪ Movie|

Example:

  • User prefers: [Sci-Fi, Adventure] (Size = 2)
  • Movie has: [Sci-Fi, Adventure, Action] (Size = 3)
  • Intersection: {Sci-Fi, Adventure} (Size = 2)
  • Union: {Sci-Fi, Adventure, Action} (Size = 3)
  • Similarity = 2 / 3 = 0.6667 (66.7%)
⚖️

2. Hybrid Recommendation Scoring

To ensure high-quality recommendations, we balance user genre preference (70%) with the movie's overall quality rating (30%):

Score = (0.70 × Similarity) + (0.30 × (Rating / 10.0))

Why this weighting?

  • Genre Relevance (70%): Strongly ensures the user receives content in their preferred genre.
  • Normalized Rating (30%): Acts as a quality tie-breaker between movies with equal genre similarity.
  • Bounded Range: Score is guaranteed to fall between 0.0 and 1.0 (0% to 100%).
💻

3. Core R Concepts Demonstrated

The project highlights foundational R data science constructs:

  • Data Frames: Parsing and validating CSV data with read.csv() and base data frames.
  • Subsetting & Filtering: Boolean vector masking like df[df$rating >= min_rating, ].
  • String Manipulation: Splitting pipe-separated genres using strsplit() and trimming with trimws().
  • Set Operations: Computing set intersection and union via intersect() and union().
  • Vectorized Sorting: Multi-level descending ordering via order(score, rating, decreasing = TRUE).
🎓

4. Quick Viva Q&A Guide

Q: Is this a Machine Learning or AI Model? A: No. It is an algorithmic content-based recommendation system using set similarity and mathematical weighting. Describing it honestly demonstrates academic integrity and clarity.
Q: What is the cold-start problem? A: When a new user has no viewing history. Our application handles this by asking explicit preferences upfront.
Q: Why R over Python for this project? A: R was specifically designed for data frames, statistical computing, and matrix operations natively without heavy libraries.
